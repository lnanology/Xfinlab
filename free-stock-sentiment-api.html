What Is FinBERT Sentiment Scoring?

FinBERT is a language model fine-tuned specifically on financial text, which scores each headline as positive, negative or neutral -- far more accurate for markets than a general-purpose sentiment model, since financial language ("beats estimates," "misses guidance," "downgrade") carries meaning a generic model was never trained to weigh correctly. This tool averages the score across a ticker's most recent headlines into one number.

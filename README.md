# XFINLAB

**投資決策數據研究平台** — Investment Decision Data Research Platform

將全球市場數據轉化為研究洞察與決策框架。

## 快速開始

```bash
cd Xfinlab-main
python3 mock-server.py
```

開啟 [http://localhost:8080](http://localhost:8080)

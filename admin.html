Video Engine
Daily AI-narrated market-signal short video (services/video_engine_service.py)
Status
Generate Now
Runs synchronously (TTS calls + ffmpeg render can take up to ~1-2 minutes). Requires the video_engine flag to be ON (Feature Flags page) and a valid GOOGLE_TTS_API_KEY set in Railway's environment variables. AI script rewrite is attempted automatically (falls back to the honest template script if it fails) -- no toggle needed.
Custom Video (chat)
2026-08-09: type a free-text request instead of using the fixed daily-signals format above -- e.g. "make a video about NVDA earnings, in Spanish, square format". Language/aspect ratio/theme are auto-detected from the text (defaults to zh-HK / 9:16 / dark if not mentioned). AI writes the narration for this specific topic -- if it can't produce a script (e.g. AI provider down), this returns an error instead of generating anything, there is no template fallback for arbitrary topics.

Formula Composer
Small-scale combinatorial strategy scan -- 35 candidate combinations (AND-pairs + 2-of-3 vote triples) of 6 existing causal indicator primitives (trend/RSI/MACD/Bollinger/OBV/Donchian), each walk-forward-validated via services/backtest_service.py before being kept.

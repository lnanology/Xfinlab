Market Sentiment Index

A confidence-weighted bull/bear ratio across today's top real signals, mapped to a 0-100 score (Extreme Fear → Extreme Greed). Refreshes whenever the visitor's page loads.

<script src="https://api.xfinlab.com/api/widgets/embed.js" data-xfl-widget="sentiment-index"></script>
Add data-xfl-theme="dark" to the tag for a dark-background version.

Signal Strength Heatmap

Today's top tickers colored by direction (green/red) with confidence as intensity -- a real signal-strength grid, not a fabricated price-change heatmap.

<script src="https://api.xfinlab.com/api/widgets/embed.js" data-xfl-widget="heatmap"></script>
Add data-xfl-theme="dark" to the tag for a dark-background version.

How it works

Each widget is a self-contained script -- no jQuery, no CSS file, nothing else to include. It renders inline wherever you place the <script> tag, fetches live JSON from api.xfinlab.com, and displays a small "Powered by XFINLAB" link. Free forever, no rate limit for normal traffic.

Tool Reliability Cards

Every API/MCP response includes an evidence block: where the data came from, when it was retrieved, which method version produced it, and whether the evidence was sufficient. Thin or empty results are reported as insufficient_evidence instead of being presented as an answer. Nothing here is investment advice.

How to read the evidence block

{
  "evidence": {
    "schema": "xfinlab.evidence/1",
    "tool": "get_sentiment",
    "retrieved_at": "2026-10-10T03:12:09+00:00",
    "data_as_of": null,
    "data_as_of_note": "Underlying data timestamp not reported by this tool.",
    "sources": ["Public RSS headlines", "FinBERT headline classifier"],
    "method_version": "sentiment-finbert-headlines/1",
    "data_status": "ok | partial | insufficient_evidence",
    "insufficient_evidence_reason": null,
    "items_used": 8,
    "limitations": ["..."],
    "not_investment_advice": true
  }
}

retrieved_at is when our server produced the response. data_as_of is the time of the underlying data and is null, with an explanation, whenever we cannot state it reliably. We never fill unknown values in.

get_market_events

What it does

Recent headlines, optionally filtered by ticker.

Sources

Public RSS news feeds; publisher named per item.

Status rules

ok with 1+ items; insufficient_evidence with none.

Known limits
  • Headlines only; claims are not independently verified.
  • Coverage and timing depend on each publisher.

get_sentiment

What it does

Classifies recent headlines for a ticker and averages the score.

Sources

Public RSS headlines; FinBERT classifier.

Status rules

ok with 3+ articles; partial with 1-2; insufficient_evidence with none.

Known limits
  • Headline-level sentiment is not a price forecast.
  • Small samples give unstable averages.

get_technical_analysis

What it does

Trend, momentum and confluence direction for one ticker.

Sources

Public market price data.

Status rules

Returns an error rather than a guess when no price data is available.

Known limits
  • Indicators are backward-looking.
  • The confidence figure is not a calibrated probability. Calibration results will be published under benchmarks/ before any such claim is made.

get_intelligence_feed

What it does

Clusters related headlines into event groups.

Sources

Public RSS headlines.

Status rules

ok with 1+ clusters; insufficient_evidence with none.

Known limits
  • Clusters are algorithmic groupings, not confirmed events.
  • Impact notes are inference, not established causation.

get_global_market_map

What it does

Regional market snapshot with optional sentiment.

Sources

Public market data and RSS headlines.

Known limits
  • Regional summaries are approximate and can lag exchange hours.

Testing and accuracy claims

We do not publish accuracy figures that we have not measured. The reproducible test plan and results are tracked in the public repository under benchmarks/. Live data-source status is at trust.html.

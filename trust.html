How Zero Fabrication Actually Works Here

This isn't a marketing claim -- it's a structural rule enforced at the code level across every data module:

1. Every metric traces to a named, cited source (FRED, SEC EDGAR, FINRA, CFTC, EIA, USDA, CBOE, FDIC, openFDA, CPSC, on-chain exchange data, etc.) -- never a model's internal estimate.
2. If a source isn't configured, is rate-limited, or genuinely has no match for a ticker, the response says so explicitly (e.g. "not configured", "no linkage found") -- it never falls back to a plausible-sounding guess.
3. AI/LLM components in this platform (sentiment analysis, narrative summaries, the AI debate engine) operate on top of real fetched data and are labeled as analysis, never presented as the underlying data itself.
4. This page's status table below is generated from the same live registry every data collector self-reports into -- not a curated snapshot.

A commitment, not just a feature list.

A common, well-documented pattern in this industry: a provider's API goes unreliable, or a "free forever" tier gets narrowed or cut with no warning, and developers building on it find out when their app breaks. XFINLAB's free tier is intentionally capped at a level the platform can run at a genuine profit on -- not subsidized to grow at a loss and then need cutting later. This is a commitment about how changes are communicated, not a guarantee that no source will ever change.
